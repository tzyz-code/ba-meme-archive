# 阶段 4 交付说明：SEO 与收录

## 交付内容

让每张表情包有**服务端渲染的独立可索引页面**，搜索引擎爬虫即使不执行 JS 也能拿到完整内容与元数据。

### 新增

| 项 | 说明 |
|---|---|
| `GET /meme/:code` | **SSR 详情页**：服务端直接返回带完整内容的 HTML，含 `<title>`、`<meta description>`、`og:*`（含 og:image 绝对地址）、`twitter:card`、JSON-LD `ImageObject`（contentUrl/thumbnailUrl 指向真实图片）、`canonical`。无 JS 也能看到图片、标签、相关档案 |
| `GET /sitemap.xml` | 动态生成：首页 / 搜索页 / 关于页 / 全部档案详情页（`/meme/:code`）/ 角色筛选页（`search.html?char=…`），含 lastmod 与 priority |
| `GET /robots.txt` | 允许抓取；`Disallow: /upload.html`（上传页不进索引）和 `/api/` |
| `detail.html` | 前端页加 `<link rel="canonical">` 动态指向 SSR 版 `/meme/:code`，避免重复收录 |

### 结构化数据（JSON-LD）

```json
{
  "@context": "https://schema.org", "@type": "ImageObject",
  "name": "标题", "description": "…",
  "contentUrl": "http://…/uploads/xxx.jpg",
  "thumbnailUrl": "http://…/uploads/xxx.jpg",
  "keywords": "…", "datePublished": "2026-10-15",
  "license": "仅供个人学习与交流使用"
}
```

### 验证结果

- SSR 页：title / og:image / JSON-LD / 图片 全部渲染，无 JS 也可读 ✅
- 404 档案返回 404 ✅
- sitemap 列出 7 个 URL（首页/搜索/关于/2 档案/2 角色）✅
- robots.txt 正确指向 sitemap ✅
- 前端 detail 页 canonical 正确指向 SSR 版 ✅

### 说明

- 站点基准 URL 通过 `req` 的 host 自动拼（本地 `http://localhost:3000`），公网部署后自动变为域名；也可用环境变量 `SITE_URL` 固定。
- 真正被搜索引擎收录还需公网可达 + 域名提交（阶段 6 部署时配置）。
