# 阶段 3 交付说明：上传 + 识图归类

## 交付内容

打通「上传 → 自动识别 → 人工校正 → 入库 → 检索展示」完整管道。

### 新增/改动

| 文件 | 职责 |
|---|---|
| `lib/classifier.js` | 识图 Provider（可插拔）。默认启发式实现：文件名/标题关键词匹配角色与 IP 字典、情绪词匹配；无法确定时低置信度进入人工校正 |
| `server.js` | 新增 `POST /api/upload`（multipart 存图+识图+暂存）、`POST /api/memes`（校正后入库，**新角色自动建目录**）、`DELETE /api/upload/:id`、`GET /api/upload`（暂存队列） |
| `db.js` | `memes` 表增加 `image_url` 字段（增量迁移） |
| `upload.html` | 真实上传：fetch 上传 → 显示识别结果 → 校正（标题/IP/角色/情绪/关键词）→ 确认入库 → 跳转详情页 |
| `data.js` / `detail.html` | 卡片与详情页优先显示上传的真实图片（`image_url`），无图时回退角色头像占位 |

### 关键机制

- **新角色自动建目录**：入库时角色不在 `characters` 表 → 自动 INSERT（`is_new=1`，稳定色相），角色馆立即可见
- **Provider 可插拔**：`registerProvider(name, fn)` 注册、`setProvider(name)` 切换。接入 CLIP/多模态 LLM 时实现同一 `classify(filePath, origName, hint)` 接口即可
- **识别置信度**：≥70 自动标记「AI 自动归类」，<70 标记「待人工校正」

### 顺手修掉的 3 个 bug

1. **搜索阈值漏洞（阶段1 潜伏）**：`0.35×IP权重` 使所有蔚蓝档案条目天然越过 0.35 搜索阈值——搜任何词都命中全部 BA 内容。修复：命中门槛只看文本相关性（新增 `textScore`），IP 权重只参与排序。前端服务端同步修复
2. **模糊匹配过宽**：单字查询触发全字段模糊命中，限制为 ≥2 字才启用模糊
3. **上传页情绪 chip 点击无效**：原实现 click 处理被 `data-act` 检查提前 return，永远到不了 chip 分支
